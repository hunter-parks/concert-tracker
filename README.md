
# 🎸 Concert Tracker

Concert Tracker is a Java application I'm building to keep track of concerts I've attended and concerts I want to see.

I started this project to strengthen my Java skills and get more hands-on experience building software from the ground up. I'm developing it step by step, starting with a console application and eventually expanding it into a full backend project.

## Current Features

- Create concert objects with artist, venue, city, and date information
- Display multiple concerts in the console
- Track an initial attendance status for each concert
- Retrieve concert information using getters
- Organize concert records using Java collections

*Currently, the application uses sample concert data. Interactive concert management is planned for future updates.*

## Technologies

- **Java** — Core application development
- **Object-Oriented Programming** — Classes, objects, constructors, and encapsulation
- **Java Collections** — Managing concert records using lists
- **Java Time API** — Handling concert dates with `LocalDate`

## Getting Started

### Prerequisites

- Java Development Kit (JDK 9 or newer)
- A Java-compatible IDE or terminal

### Running the Application

1. Clone or download this repository.
2. Open the project folder in your IDE or terminal.
3. Compile the application using `javac Concert.java ConcertTrackerApp.java`.
4. Run it using `java ConcertTrackerApp`.

The application will display the sample concerts and their information in the console.
